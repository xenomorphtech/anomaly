Context OS — 10 interface paradigms

Ten different answers to the same problem: managing many unrelated projects and goals without strict classification, absorbing agent status reports, and re-orienting fast when a decision has to be made. Same fake world in every mock — only the paradigm changes.

Every mock demonstrates the same core workflows: Capture a thought without classifying it  ·  Agent report arrives (simulate button)  ·  Orient — re-read accumulated context behind the pending “gate desync” decision, then commit. Look for the “Try the workflows” hint panel on each page.

Round 2 — RTS-informed hybrids

Converged designs. Each fuses several round-1 dimensions and implements the full RTS contract learned from top-level play: an always-visible glance surface with event pings, constant-time navigation (1–4, Space = jump to alert, Esc = camera back), alerts that never steal the viewport, an idle/blocked-agent button, fog-of-war staleness on untouched contexts, a ~10-second 1 2 3 4 sweep with delta-first resumes, and deep re-read only as the fallback for cold contexts.

11Commander

The literal RTS

Projects as bases on a map, agents as units, minimap with viewport rect, command card, attention-budget resource bar.

Fuses: spatial canvas + fleet board + resume cards.

 12Operations HUD

Stable chrome, swappable center

The frame never changes — rail, ticker, minimap, fleet bar. The center renders each project as Brief, Thread, or Board.

Fuses: briefs + thread chat + boards + fleet, in RTS chrome.

 13Patrol

The macro cycle, reified

Tab through a rehearsed rotation of delta-first resume cards with inline triage; staleness dials reset as you sweep.

Fuses: context stack + inbox triage + replay recovery.

 14Starmap

The minimap IS the interface

Semantic zoom: world → star system → event log, one continuous space, camera flights instead of navigation.

Fuses: spatial + graph structure + timeline.

 15War Room

Interrupts left, truth center, forces right

A triage queue feeding a state-of-the-world brief, with every agent in a production bar. Dense keyboard layer.

Fuses: inbox + living briefs + fleet + TUI density.

Round 1 — ten pure paradigms

01Mission Control

Flight-director dashboard

Project lanes, an agent fleet board, and an alert strip for anything needing you. Everything at a glance, nothing hidden.

Best when: many agents running, you mostly supervise.

 02Timeline · Journal

One chronological stream

All projects interleaved in a single narrative log with decision flags and a replay mode that retraces how you got here.

Best when: orientation = re-reading the story.

 03Spatial Canvas

Projects as places

Pan and zoom an infinite map; clusters instead of folders, captures floating homeless between them — legitimately unclassified.

Best when: spatial memory is how you think.

 04Inbox · Triage

Everything arrives, you triage

Agent reports, captures and decisions land in one inbox; assign, snooze, or resolve. Zero-inbox as the rhythm of control.

Best when: you want a forcing function, not a view.

 05Thread-centric

Each project is a conversation

Agents talk in project channels; decisions are pinned messages; re-reading is just scrolling back through the thread.

Best when: agent dialogue is the primary record.

 06Graph View

Goals → projects → tasks as nodes

Status lives on the graph: working agents pulse, blocked ones ring red. Expand the decision node to fan out its history.

Best when: structure and dependencies matter most.

 07Fluid Boards

Kanban without the walls

Swimlanes per project over a soft todo→done gradient; cards can live between lanes, because not everything classifies.

Best when: you think with your hands, dragging things.

 08Living Documents

A brief per project

Each project is a document with a maintained “state of the world” on top and an append-only log where agent updates land as diffs.

Best when: prose is your source of truth.

 09Terminal · TUI

tmux for your life

Panes, box-drawing borders, an agent table, a scrolling event log, and a : command palette. Keyboard-first, maximum density.

Best when: you live in a terminal anyway.

 10Context Stack

Push, pop, resume

An explicit stack of working contexts; every card is a resume card — where you left off, what changed since, what's pending.

Best when: context-switching itself is the enemy.
