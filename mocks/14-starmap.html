STARMAP semantic zoom — the minimap is the interface · fuses spatial (03) + graph (06) + timeline (02) ← index

Try the workflows

  1. Capture — press c (or ⊕ capture, bottom-left), type, enter. It lands in the Drift as an unsorted comet — no classification forced.
  2. Alert contract — press ▶ simulate report (or wait ~8s). Only a ping + toast + badge appear; the view never moves. space jumps to it, esc flies you back via the breadcrumb.
  3. The sweep — press 1 2 3 4. Each system opens delta-first; fog burns off as you visit.
  4. Idle button — click ◉ idle/blocked (or press i) to cycle market-bot → navigator with reasons and next actions.
  5. Deep recovery + decision — fly to 3 Paper or 4 Apartment for the recovery briefing; open Albion’s amber ◆ beacon → replay the context → commit. Navigator unblocks, count drops 2 → 1.

Strengths / weaknesses

Strengths
  • Zero navigation chrome — one continuous camera from glance to detail to history; spatial memory does the indexing.
  • Staleness, blockage and events are preattentive: fog, red blink, amber beacons read in a sub-second glance.
  • Zoom depth maps to attention depth — you literally cannot open detail without passing the delta summary.
Weaknesses
  • The spatial metaphor caps density — dozens of projects would crowd the sky.
  • Text-heavy work (long logs, documents) fights the zoom metaphor; eventually needs flat panels.
  • Orbital whimsy has a novelty tax — pure keyboard operators will be faster in a TUI.
