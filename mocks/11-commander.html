Try the workflows ✕

  1. Capture — press c (or the ⚡ command button), type a thought, enter. It drops instantly into the drifting-captures field mid-map. No classification asked.
  2. Alert contract — click ▶ simulate agent report (one also auto-fires ~8s after load). Watch: minimap ping + corner toast + unseen counter only — the camera never moves. Then space jumps to it, esc flies you back.
  3. The sweep — press 1 2 3 4 in sequence. Each base opens with a delta-first resume header ("since you left…"), and its fog of staleness burns off as you visit.
  4. Idle button — click the 🛌 button (or i) twice to cycle through the 2 idle/blocked units and see why + a suggested order.
  5. Deep recovery + decision — press 3 (cold Paper) or 4 (frozen Apartment) and open the ⟲ recovery briefing; then on Albion open the amber ◆ decision flag → re-read the accumulated intel → commit a fix. Navigator unblocks, idle count drops.

ⓘ Honest compare ✕

+ Strengths

  • Spatial permanence: every project lives at a fixed map position, so glancing, pinging and jumping become muscle memory — true sub-second orientation.
  • The RTS grammar (minimap, idle button, hotkey camera) is a proven design for supervising many semi-autonomous units under interrupt pressure.
  • Fog + delta-resume make staleness literally visible and re-entry cheap.

− Weaknesses

  • Spatial metaphor spends screen space; dense text work (long briefs, threads) still needs an overlay, not the map.
  • Game chrome can feel like cosplay for serious work; the metaphor strains past ~8 projects.
  • Hotkey-first design has a learning curve; mouse-only users lose half the speed.
