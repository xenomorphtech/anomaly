💬 Threads Thread-centric chat — every project is one long-running conversation; agents and you talk in the same channel, so the scrollback is the context. index

Try the workflows

  1. Capture — press c anywhere (or the ＋ Quick capture button, or just type in #capture). It lands in #capture, unsorted.
  2. Agent report — click ▶ simulate agent report (also auto-fires ~8s after load). packet-tracer posts into #albion; you get an unread badge if you're elsewhere.
  3. Orient for a decision — open #albion and click the 📌 pinned decision bar (or “↺ re-read history” on the card). The channel scrolls back through the 7-entry decision log, then lands on the commit buttons.

Strengths

  • Chronology is native — the scrollback literally is the project memory.
  • Agent reports read like teammates talking; zero ceremony to absorb them.
  • One place per project; capture is just “say it in #capture”.

Weaknesses

  • Structure drowns in the stream — tasks and status must be pinned or they scroll away.
  • Re-orientation means literally re-reading; slow when the log is long.
  • Cross-project overview requires channel-hopping; no single glance.
